# Heart Disease Prediction

A small Python machine-learning project that trains a Random Forest classifier on heart patient data and uses the saved model to make a sample prediction.

## Project Description

- Heart Disease Prediction is a beginner-friendly machine-learning project.
- It demonstrates a basic supervised classification workflow in Python.
- The project uses patient records stored in `heart.csv`.
- Each row represents one record from the dataset.
- Patient measurements and categorical values are used as model features.
- The `HeartDisease` column is the target the model is trained to predict.
- The training script is `heartatt.py`.
- The script loads the dataset with pandas.
- Categorical columns are converted into numeric labels.
- The encoded records are written to `heartatt.csv`.
- The data is split into training and test sets.
- A Random Forest classifier is created with scikit-learn.
- The model is fitted using the training data.
- The held-out test data is used to evaluate the model.
- The script prints a classification report.
- It also prints the model's accuracy score.
- The trained model is saved as `heart_model.pkl`.
- The saved model can be loaded with joblib.
- The sample prediction script is `predict.py`.
- It creates a sample patient record for prediction.
- The prediction script prints the model's predicted class.
- The project uses Python, pandas, scikit-learn, and joblib.
- Follow the setup instructions below to install these dependencies.
- Run the training script before running the prediction script.
- The dataset and generated files should be kept in the project directory.
- Results depend on the dataset, preprocessing, and model configuration.
- This repository is intended for education and experimentation.
- It is not a clinically validated diagnostic system.
- Do not use its output to make healthcare decisions.
- Always consult a qualified healthcare professional about health concerns.

> **Disclaimer:** This project is for learning and demonstration only. It is not a medical device and must not be used to diagnose, treat, or make decisions about a person's health.

## Features

- Reads patient records from `heart.csv`.
- Encodes categorical columns and writes the encoded data to `heartatt.csv`.
- Trains a `RandomForestClassifier` and reports classification metrics.
- Saves the trained model as `heart_model.pkl`.
- Includes `predict.py` for a sample prediction.

## Project files

| File | Description |
| --- | --- |
| `heart.csv` | Source dataset used to train the model. |
| `heartatt.py` | Data preparation, training, evaluation, and model saving. |
| `heartatt.csv` | Encoded dataset generated by `heartatt.py`. |
| `heart_model.pkl` | Serialized trained model generated by `heartatt.py`. |
| `predict.py` | Loads the saved model and predicts for the sample patient in the script. |

## Requirements

- Python 3
- pandas
- scikit-learn
- joblib

## Setup

Open a terminal in this project directory and create a virtual environment:

```powershell
python -m venv .venv
```

Activate it in PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Or activate it on macOS/Linux:

```bash
source .venv/bin/activate
```

Install the required packages:

```bash
python -m pip install pandas scikit-learn joblib
```

## Train the model

Run:

```bash
python heartatt.py
```

The script prints a classification report and accuracy score. It also creates or overwrites `heartatt.csv` and `heart_model.pkl` in the current directory.

## Make a sample prediction

After training, run:

```bash
python predict.py
```

The sample patient values are defined in `predict.py`. Edit those values to try another patient, using the feature names and category values represented in `heart.csv`.

> **Known limitation:** The `ChestPainType` mappings in `predict.py` do not match the label encoding learned by `heartatt.py`. As a result, predictions from `predict.py` may be incorrect. The prediction preprocessing should be updated to reuse the training encoders before relying on its output.

## Dataset columns

The input CSV is expected to contain these columns:

`Age`, `Sex`, `ChestPainType`, `RestingBP`, `Cholesterol`, `FastingBS`, `RestingECG`, `MaxHR`, `ExerciseAngina`, `Oldpeak`, `ST_Slope`, and `HeartDisease`.

`HeartDisease` is the target column; the remaining columns are used as model features.
